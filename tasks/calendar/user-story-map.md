# Карта реализации истории (КРИ)

## Контекст
Сотрудник склада принимает новую партию товара.  
Карточка товара уже существует, количество указывается вручную.  
Необходимо зафиксировать дату истечения срока годности, указанную на упаковке.

---

## Цель пользователя
Сотрудник склада хочет указать срок годности товара, чтобы система могла корректно учитывать сроки хранения и предотвращать использование просроченных товаров.

---

## Пользовательская история
**Как** сотрудник склада,  
**я хочу** выбрать дату истечения срока годности в карточке товара,  
**чтобы** корректно зафиксировать срок хранения при приёмке.

---

## Основной сценарий (happy path)

1. Пользователь открывает карточку товара.  
2. Видит поле «Срок годности» рядом с полем количества.  
3. Нажимает на поле даты.  
4. Открывается компонент календаря.  
5. Пользователь выбирает дату, указанную на упаковке.  
6. Выбранная дата отображается в поле.  
7. Пользователь нажимает кнопку «Сохранить».  
8. Система сохраняет дату срока годности вместе с количеством товара.

---

## Реакции интерфейса

- При фокусе на поле даты открывается календарь.
- Календарь позволяет выбрать конкретный день.
- После выбора даты:
  - календарь закрывается;
  - выбранная дата отображается в поле.
- Кнопка «Сохранить» активна, если заполнены обязательные поля.
- После сохранения отображается подтверждение успешного действия.

---

## Альтернативные сценарии и ошибки

- Если дата не выбрана:
  - сохранение недоступно (если срок годности обязателен).
- Если пользователь пытается выбрать прошедшую дату:
  - дата недоступна для выбора **или**
  - показывается сообщение об ошибке.
- Если календарь закрыт без выбора:
  - значение поля не изменяется.
- Если изменено только количество:
  - ранее заданная дата сохраняется без изменений.

---

## Ограничения

- Компонент используется внутри карточки товара.
- Используется стандартный календарный контрол.
- Ввод даты возможен только через выбор в календаре.
- Формат даты единый для всей системы.
- Компонент корректно работает на мобильных и десктопных устройствах.
- Минимальное количество действий для выбора даты.

---

## Критерии готовности (Acceptance Criteria)

- В карточке товара присутствует поле «Срок годности».
- При клике по полю открывается календарь.
- Пользователь может выбрать дату.
- Выбранная дата отображается в поле.
- Дата сохраняется при нажатии «Сохранить».
- Нельзя сохранить некорректную дату.
- Поведение компонента предсказуемо и повторяемо.
- Работа компонента не мешает вводу количества товара.
