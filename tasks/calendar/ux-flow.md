# UX Flow: выбор срока годности в карточке товара

## Назначение документа

Этот документ описывает UX-поток (UX flow) взаимодействия пользователя с элементом интерфейса выбора срока годности товара.  
Предназначен для использования в репозитории проекта как описание логики поведения интерфейса.

---

## Контекст

Сотрудник склада принимает товар на мобильном терминале для учета товара.  
В карточке товара уже существует поле ввода количества.  
Необходимо добавить возможность указать срок годности, указанный на упаковке.  
Компоненты календаря и карточки товара оптимизированы для использования на мобильных терминалах.

---

## Цель пользователя

Как сотрудник склада,  
я хочу указать дату истечения срока годности товара,  
чтобы система могла корректно учитывать сроки хранения и предотвращать использование просроченных товаров.

---

## Пользовательская история

**Как** сотрудник склада,  
**я хочу** выбрать дату истечения срока годности в карточке товара,  
**чтобы** зафиксировать срок хранения при приёмке.

---

## Основной UX-поток

```

Открыть карточку товара
↓
Увидеть поле «Срок годности»
↓
Нажать на поле
↓
Открывается календарь
↓
Выбрать дату
↓
Календарь закрывается
↓
Дата отображается в поле
↓
Нажать «Сохранить»
↓
Данные сохранены

```

---

## Состояния компонента

### 1. Пустое состояние

Дата не задана, отображается плейсхолдер:

```

Срок годности: —

```

---

### 2. Активное состояние

Поле находится в фокусе, открыт календарь:

```

Срок годности: |
↓
Календарь

```

---

### 3. Заполненное состояние

Пользователь выбрал допустимую дату:

```

Срок годности: 12.03.2026

```

---

### 4. Состояние ошибки

Недопустимая дата (например, прошедшая).

Поведение:
- такие даты недоступны для выбора  
  или  
- отображается сообщение об ошибке

---

## Альтернативные сценарии

### Пользователь открыл календарь, но не выбрал дату

```

Открыть календарь
↓
Клик вне области / закрытие
↓
Календарь закрыт
↓
Значение не изменилось

```

---

### Пользователь изменил только количество

```

Изменить количество
↓
Срок годности не изменён
↓
Нажать «Сохранить»
↓
Сохраняется только количество

```

---

## Правила взаимодействия

- Ввод даты возможен только через календарь  
- Ручной ввод запрещён  
- Прошедшие даты недоступны  
- После выбора дата сразу отображается  
- Компонент не перекрывает кнопку «Сохранить»  
- Работает на мобильных и десктопных устройствах  
- Календарь открывается на весь размер экрана устройства для удобного выбора даты на мобильном терминале  
- Минимальное количество действий для выбора даты  

---

## Критерии готовности (Acceptance Criteria)

- Поле «Срок годности» отображается в карточке товара  
- Клик по полю открывает календарь  
- Пользователь может выбрать допустимую дату  
- Выбранная дата отображается корректно  
- Некорректные даты недоступны  
- Данные сохраняются при нажатии «Сохранить»  
- Поведение компонента стабильно и предсказуемо  

---

## Краткий итоговый поток

```

Открыть карточку → выбрать дату → сохранить

```
